# Sign Up Page – DOM Manipulation with Local Storage

This project is a simple **Sign Up page** developed using **HTML, CSS, and JavaScript**. It demonstrates **DOM Manipulation** and how to use **Local Storage** to store user input data.

## 🔧 Features

- Collects user details such as First Name, Last Name, Email, and Password
- Validates form input
- Stores data in the browser's **Local Storage**
- Prevents form submission if fields are empty
- Basic UI with interactive feedback

## 📚 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage

## 📂 How to Use

1. Clone this repository or download the ZIP file.
2. Open the `index.html` file in your browser.
3. Fill in the sign-up form and submit.
4. Data will be saved in your browser's local storage.

## 🧠 Learning Outcomes

- DOM selection and event handling
- Input validation using JavaScript
- Storing and retrieving data using `localStorage`
- Basic front-end form logic
